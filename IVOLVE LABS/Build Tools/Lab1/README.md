# Lab 1: Maven Calculator App

## How to Run

1. Navigate to project folder:
```bash
cd ~/Ivolve-lab1/CalculatorMavenApp
```

2. Build and package:
```bash
mvn clean package
```

3. Run the application:
```bash
java -jar target/calculator-1.0-SNAPSHOT.jar
```
